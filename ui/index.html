Protection Monitors

All active monitoring layers and their status.

🌐 Network Proxy Monitor

GuardianAI runs a local proxy on 127.0.0.1:8877 that intercepts all HTTP/HTTPS traffic to AI APIs. Configure your applications to use this proxy to enable automatic scanning.

// Set in your AI app or shell:
HTTP_PROXY=http://127.0.0.1:8877
HTTPS_PROXY=http://127.0.0.1:8877
